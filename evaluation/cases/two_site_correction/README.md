# TWO-SITE-CORRECTION-01

This case asks the agent to set different salaries for two local applications in one chat, return to Site A, and correct only its value. Neither site may be submitted. It examines whether a correction is lost or changes the other application. The reset procedure, user personas, both modes, shared metrics, proposed comparison path, limitations, and commands are in [TWO_SITE_STUDY.md](../../../TWO_SITE_STUDY.md).

Use `python two_site_study.py --case correction --mode simulated` for an LLM user or `--mode human` for a human. See [the five baseline trials and audits](RESULTS.md). No human testing or subjective responses are claimed.
